## Zendure Monitor 1.2.0

### New
- **Multi-day production history** 📅 — new "History" card with a daily kWh bar chart (last 14 days shown, 90 days kept), period total, today highlighted
- **Menu bar display options** — choose what is shown next to the icon: solar W, battery %, home W (or icon only)
- **Launch at login** toggle
- **Low-battery notification** with configurable threshold (5–50%)
- **Today's solar energy** counter in the production card
- **Per-pack details** in the battery card: SOC, temperature, power
- **Remote access fallback host** — tried automatically when the local address doesn't answer (use with a VPN such as Tailscale; never expose the device to the internet)
- **Tabbed settings** (Device / Display / General / Notifications / Remote)
- **French & English** localization, follows the system language
- **Theme override**: Auto / Dark / Light

### Notes
- macOS 14+, signed and notarized. Auto-update via Sparkle.
