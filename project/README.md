# Project documents — ZendureMonitor

These are the **working documents** behind ZendureMonitor, published as-is so anyone can see how the app was specified, planned and built — decisions, dead ends and lessons included. They were written day to day during development (with an AI coding assistant, Claude Code), in French; an English translation sits next to each original.

| Document | What it is | Français | English |
|---|---|---|---|
| PRD | Product requirements: problem, principles, personas, numbered requirements (F-01…F-94), roadmap, risks, open questions | [PRD.md](fr/PRD.md) | [PRD.md](en/PRD.md) |
| PLAN | Implementation plan, phase by phase | [PLAN.md](fr/PLAN.md) | [PLAN.md](en/PLAN.md) |
| CHANGES | Detailed, dated change log (Added / Changed / Fixed / Decisions) | [CHANGES.md](fr/CHANGES.md) | [CHANGES.md](en/CHANGES.md) |
| TODOS | Task list — done, next, backlog | [TODOS.md](fr/TODOS.md) | [TODOS.md](en/TODOS.md) |
| MEMORY | Project state, structural decisions and pitfalls learned | [MEMORY.md](fr/MEMORY.md) | [MEMORY.md](en/MEMORY.md) |
| COMMANDS | Numbered log of every request made during development, with what was done | [COMMANDS.md](fr/COMMANDS.md) | [COMMANDS.md](en/COMMANDS.md) |

**Snapshot.** These files are a snapshot taken on 2026-10-03 (v2.3.0). The originals keep evolving in the author's working copy; this folder is refreshed from time to time.

**Anonymized.** Personal details were replaced with bracketed placeholders: device serial numbers (`[SN-1]`, `[SN-2]`, `[SN-CT]`), local IP addresses (`[IP-SolarFlow-1]`…), Wi-Fi name, cloud device keys, home coordinates and host names (`[Mac-collecteur]` = the always-on Mac running the 24/7 collector). Everything else is unchanged.

For user documentation, see the [README](../README.md) and the [user guide](../docs/guide/).
